# Campus Vehicle Management System

## Overview
The Campus Vehicle Management System is a Python-based application designed to manage vehicles, users, bookings, trips, and reports within a college campus. It provides a simple menu-driven interface for performing different management operations.

## Features
- Add, view, search, and delete vehicles
- Add, view, search, and delete users
- Manage vehicle bookings
- Manage trip records
- Generate reports and system summaries
- Input validation and error handling
- Simple menu-driven interface

## Technologies Used
- Python
- Visual Studio Code
- Git and GitHub

## How to Run
1. Install Python.
2. Download or clone the project.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run:

python main.py

## Testing
The project can be tested by selecting each option from the main menu and checking the Vehicle, User, Booking, Trip, and Report modules.

Invalid menu choices can also be entered to verify the error-handling functionality.

## Project Modules
1. Vehicle Management
2. User Management
3. Booking Management
4. Trip Management
5. Reports
