# Problem Statement

Managing campus vehicles, users, bookings, and trip information manually can be time-consuming and difficult. The Campus Vehicle Management System provides a simple Python-based solution for organizing and managing these records through a menu-driven application.

# Scope of the Project

The project focuses on basic campus transportation management. It allows vehicle records, user records, bookings, and trips to be created, viewed, searched, and deleted. It also provides reports summarizing the stored information.

# Target Users

The primary target users are college or university staff responsible for managing campus transportation and vehicle-related records.

# High-Level Features

- Vehicle Management
- User Management
- Booking Management
- Trip Management
- Reports and System Summary
- Search and Delete Operations
- Input Validation
- Error Handling
- Simple Menu-Driven Interface
